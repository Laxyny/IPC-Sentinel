## Evidence and decisions

TypeScript 7's [official announcement](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) describes the new API architecture. The analyzer directly uses createProgram, TypeChecker, syntax nodes and static reduction; migrating this production dependency requires an explicit adapter/migration project with corpus equivalence checks. Forcing installation through the peer failure would not establish compatibility. No forced installation or automatic major migration was attempted.

Vitest 5's [migration guide](https://vitest.dev/guide/migration/) requires Node ^22.12 or ^24 or >=26 and Vite >=6.4. The supported CI targets Node 22 and 24 satisfy this. Test tooling is not shipped as production dependencies. The changed clearMocks default does not affect the suite's current non-mocked fixtures, and coverage globs were checked. The paired lockfile passed npm ci, npm ls, full validation, coverage and a zero-vulnerability audit in an isolated checkout. All four public baseline projects retained their analyzer counts with the development-only update. Both individual PRs originally failed because the exact Vitest/coverage peer versions diverged.

PR #3 was augmented with the coverage change while preserving its history. Its final reviewed head was ff3cf7e7cc5d8da7e46ac9e5ee58c0b824012b8a; validation run 38187243398 succeeded on Windows, macOS and Linux with Node 22 and 24 before merge. The normal merge produced main commit 68b539b11a558d7e828547f213929feaaaa9a616. Repository rulesets returned no additional rules; the branch-protection read was denied to the integration, so the normal merge operation was used without a bypass. The main feature branch remains unmerged.

The Node types update was independently installed and tested with the existing compiler, including packaged imports, CLI, coverage and audit. The original publication dry-run failure was unrelated to declarations and had already been fixed on main. Passing today does not justify exposing Node 26 APIs in a package supporting Node 22; no security benefit requiring this major declaration update was demonstrated.

Dependabot now groups vitest and @vitest/* updates so exact peer upgrades arrive together. Major @types/node updates are ignored while the minimum runtime remains Node 22; compatible patch/minor updates continue. TypeScript major proposals remain visible for explicit review. CI and audits do not prove absence of supply-chain compromise, but no dependency vulnerability was reported by the performed npm audits.
