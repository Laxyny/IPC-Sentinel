## Implemented architecture

project.ts owns root-contained relative config inheritance and Electron package-boundary discovery. An empty nearer config prevents leaking aliases from a parent project. Config inheritance preserves declaring directories, ordered parent overrides, cycles/resource bounds and real-path containment. Nested ambiguous Electron packages produce IPC008 and leave relationships unassigned. Explicit roots override inference; multiple windows/preloads inside one app remain together.

wrappers.ts adds direct function-returning factories and constant preludes to imported/re-exported/object/ESM/CommonJS forwarding. It rejects guarded/side-effecting factories, parameter defaults and stateful classes. Function and handler summaries are cached only for one scan; a source-mutation regression verifies that repeated scans do not reuse stale results.

handler.ts records selected privileged effects, syntactic IPC input dependencies and early-exit guard locations through bounded local helpers. Evidence never proves control-flow dominance or validation correctness. IPC001 additionally reviews raw Node bridge capabilities and renderer-input dependencies into privileged operations, follows event aliases, and accepts primitive event metadata extraction. IPC009 adds unconditional child-window permission on proven BrowserWindow receivers. No new rule IDs or breaking report version were needed.
