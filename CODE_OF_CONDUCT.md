# Code of conduct

Participants must communicate respectfully, focus criticism on work rather than people, and accept that contributors have different backgrounds and experience levels. Harassment, discrimination, threats, unwanted sexual attention, disclosure of private information, and deliberate disruption are unacceptable.

This applies to repository issues, pull requests, discussions and project-related public interactions. Maintainers may remove inappropriate content, limit participation, or exclude participants after considering context and severity. Decisions should be proportionate and protect affected participants' privacy.

Report concerns privately to the repository owner using an available private contact channel on their GitHub profile. If no private channel is available, request contact without posting personal details publicly. Maintainers should acknowledge reports, review evidence impartially and communicate the outcome privately where practical. Do not retaliate against someone reporting a concern in good faith.
